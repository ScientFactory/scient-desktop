# Agent guidance

<!--
This is minimal starting guidance for agents working on an evolving project.
Refine it with the user as durable project needs become clearer.
Keep it concise and remove, replace, or reorganize guidance when that improves the project.
-->

- Read `PROJECT.md` before substantial work and use it to understand the project's current context and direction.
- Follow explicit user instructions and established project decisions. When genuine ambiguity remains, understand the intended outcome and use first-principles reasoning to avoid unsupported assumptions—not to override instructions or overcomplicate routine work.
- Adapt to the project's actual goals, terminology, materials, and working style. Do not impose a domain, methodology, workflow, or output format.
- Do not invent facts, sources, results, decisions, or requirements. Make consequential assumptions and uncertainty explicit.
- Preserve user-authored context and instructions. Do not rewrite them merely to match a template or preferred structure.
- Maintain `PROJECT.md` and `AGENTS.md` with the user when durable project context materially changes. Keep them slim and useful; do not update them automatically after every task or add rules without a reason.
