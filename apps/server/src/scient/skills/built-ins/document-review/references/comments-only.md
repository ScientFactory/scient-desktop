# Prove a Word review changed only comments

Read for a comments-only delivery that must preserve existing Word content and review markup.

1. Locate each span in the original across run boundaries or search on a disposable copy. Add the anchors and comments to a fresh copy of the untouched package. Record the new comment IDs, span text and any runs split at anchor boundaries. Done when the recorded IDs resolve to their exact spans after reopening.
2. Compare ZIP member names and uncompressed bytes. For the CT9 wheat manuscript, the expected new members were `word/comments.xml`, `word/commentsExtended.xml`, `word/commentsExtensible.xml` and `word/commentsIds.xml`. The expected changed members were `[Content_Types].xml`, `word/_rels/document.xml.rels` and `word/document.xml`. The contents and relationships changes registered only the new comment parts. If a package already has comment parts, check the existing entries individually. Done when each package difference has an explanation tied to the added comments and no member has disappeared unexpectedly.
3. On an analysis copy of the edited XML, remove the `w:commentRangeStart`, `w:commentRangeEnd` and `w:commentReference` nodes for the recorded new IDs. Remove only the generated reference runs that become empty. For a boundary split, join only the recorded fragments of the same original run and restore its run properties and text spacing. Compare the canonical XML with the baseline. Repeat for every edited content part. Done when the comparison proves equality and the published copy still contains the verified comment anchors.
