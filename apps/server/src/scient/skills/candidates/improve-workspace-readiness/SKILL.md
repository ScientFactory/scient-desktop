# Improve Workspace Readiness

Improve readiness by removing material obstacles to understanding the work, acting safely, reproducing it, or judging whether results are correct.

Use a recent readiness review when available, but verify the relevant workspace evidence before changing it. Without a review, inspect only enough to identify grounded improvements.

Prefer the smallest coherent changes that address the user's request. Keep documentation truthful and consistent with the workspace. Preserve existing intent and user-authored material. Do not reorganize, rename, remove, broadly rewrite, or change tooling merely to enforce conventions. Ask before destructive, structurally disruptive, or materially broader changes.

This skill provides guidance only and grants no tools or authority. After making changes, verify them where practical. Report exactly what changed, where it changed, and why each change meaningfully improves readiness. Mention any important recommendation that remains unapplied.
