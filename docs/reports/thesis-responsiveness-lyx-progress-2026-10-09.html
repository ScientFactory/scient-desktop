Thesis responsiveness: progress toward LyX

Scalar LQG Communication Capacity · Windows · 9 October 2026

The current production build is faster in the measured typing sequence, with editing and recovery checks passing. LyX parity is not established.

The 50 ms p95 typing target remains unmet. Fresh document DOM installation and some layout stages still occupy the main thread. No equivalent visible-input benchmark against native LyX was obtained; a hidden import and pipe acknowledgements are not a substitute.

Production comparison

Each sequence uses 24 character keys plus End. The corrected driver presses and releases each key, then pauses 60 ms before the next. A separate current run retaining the old key-hold method measured a 70.5 ms timer proxy and 64 ms Event Timing p95. These are single sequential runs, not a statistical guarantee or identical system-load control. Post-forced-GC heap was about 77 MiB in both production builds; lower observed heap during typing is not evidence of lower retained memory by itself.

Event Timing is browser event-to-render-update duration, rounded to 8 ms and reported with a 16 ms threshold. All 25 keydown events were reported in these runs. The older animation-frame-plus-task timer can include work after paint. Neither measures physical screen scanout. Opening measurements include settle waits and automation; main-thread task CPU excludes worker CPU.

Changes, one by one

Area Implemented in this round Remaining limit
Local typing Object views subscribe only to relevant presentation state. Reference display omits moving source positions; clicks resolve current targets. Preamble-stable authoring context avoids source-wide notifications. ProseMirror transactions and React/DOM work remain on the renderer thread.
Background processing Large initial projections, quiet ordinary-text conversion, and large reference/bibliography indexes use a serial worker. Canceled or stale results cannot publish. Mandatory flushes and structural commands retain guarded synchronous paths. Other source metadata still runs locally.
Pagination Yields between spacing, measurement and planning; restores flags before a yield; rejects superseded work. Existing immutable-block caches remain. Individual DOM measurement and installation stages remain atomic. Async span duration includes time spent yielding.
Visible content One observer prioritizes nearby formula jobs. Browser rendering containment skips distant paragraphs and display math using pagination-owned height decorations. Print and thumbnails render complete snapshots. This preserves the full ProseMirror DOM. It is not complete editor-node virtualization.
App updates Memoized file surface, quiet closed reference dialogs, stable reference callbacks. Thumbnails share CSS-variable reads and defer during typing. Production source-mapped samples still show substantial React/browser work; development instrumentation adds much more.
Progressive opening Large preparation happens off-thread, with Source available and retry on failure. Nearby formulas get priority; reading creates no live math editors. Mounting the complete document is still a noticeable synchronous cost. All-preview settle time is not first-editable time.
LyX comparison Located installed LyX 2.3.6 and imported the assembled 52,307-character thesis into an isolated profile. Recorded import coverage and attempted named-pipe diagnostics. LyX import has 446 Formula insets and 82 ERT insets versus Scient's 422 previews; workloads are not rendering-equivalent. No accepted visible input-to-paint baseline exists.

Editing, layout and stronger protection

Production rendered all 422 formulas with zero live inputs while reading. Eight incremental-versus-full layout checks agreed at 14 pages: initial, last-page scrolling, return to first page, paragraph edit/undo, math edit/undo and view return. Whole-document selection covered offscreen objects and copied 49,769 characters through an internal clipboard event, without changing the user's system clipboard.

Mouse/touch entry, menu selection, Ctrl+Enter, native undo, command completion, and page thumbnails completed without renderer errors. Visiting 14 formulas retained at most eight live inputs, with model and native undo restored after suspension. Ten storage/version recovery guards passed. Worker projection, source conversion, 77 reference targets, a synthetic 1,000-entry bibliography, request cancellation, aborted promises, startup failure and retry were checked.

A rejected intermediate change wrote heights directly to editable paragraph attributes and caused repeated preview rebuilds. The accepted version uses ProseMirror decorations. It also retains an unchanged preview request while it is in flight. The failed capture is retained under the local phase3 archive; it is not counted as a speed result.

No formal test suites were run, following project instructions. Web type checking and formatting passed. Targeted lint completed with warnings, including rules that mistake worker postMessage for window postMessage; it is not a warning-free lint result.

Limits and evidence

        

        

          Development remains much slower than production. Its dependency-cold opening includes Vite
          compilation and thousands of requests; cached reload uses the same prepared dependency
          graph. The current round measures the browser renderer, not a fresh Electron main-process
          capture. The prior native report is retained, and this round does not claim to prove that
          every Scient workflow is freeze-free.
        

        

          Next unresolved work is finer-grained DOM measurement/installation, reducing remaining
          React/browser work, and a rendering-equivalent visible LyX comparison. These remain open
          rather than being marked complete.
