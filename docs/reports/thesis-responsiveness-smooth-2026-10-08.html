Making thesis Visual editing smoother

Scalar LQG Communication Capacity · Windows · 8 October 2026

All 422 formulas rendered in the native Electron capture. Opening, typing, undo, scrolling, Source/Visual/PDF switching, close/reopen, and cached reload completed without renderer errors. Original authored thesis files were read and copied; all scripted edits used the diagnostic copy.

Typing is much better than the original baseline, but opening and pagination still contain long tasks. These are single observed runs, not a guarantee against freezes in every Scient workflow.

Measured production response

Typing: 25 keydown-to-animation-frame-plus-task samples per sequence, a next-paint proxy rather than end-to-end display latency. Task CPU excludes worker CPU. Opening includes settle waits and automation, so elapsed intervals are not first useful paint. Same workstation and copied thesis; source snapshots and system load differ between runs.

Implemented

  • Local pagination measurements reuse immutable unchanged blocks, paragraph line/spacing results, and footnote heights. Edits and preview/resize events invalidate the affected block and neighbors. Global typography, dimensions, fonts and reference presentation still trigger full invalidation. The pagination plan still visits the whole document to keep downstream page breaks correct.
  • Equivalent document macro/color contexts keep the same preview identity after source reparsing. Unchanged math retains its rendered DOM. A worker receives the shared dictionary once per context instead of once per formula; both semantic and worker context caches are bounded.
  • Background DOM batches yield after paint with a 4 ms budget and pending-input priority. Hover alone no longer allocates a math editor; pointer entry and keyboard editing still activate the native editor.
  • Native math inputs use a soft limit of eight. Only inactive, acknowledged, clean, collapsed inputs can suspend; active selection, menu retention, composition, command entry and unpublished drafts take priority. Suspension retains plain model data, empty slots, selection/mode and the native undo stack. Guarded MathLive adapters keep incompatible inputs alive; authoritative source remains the recovery boundary.
  • Existing worker timeouts/output bounds and version-aware recovery journals remain active. Failed rendering keeps exact source editable. Pool trimming does not flush or discard an unpublished edit to meet its limit.

Remaining costs and limits

      

        

        
    
          
  • 
            First document projection and large DOM/layout installation are still atomic main-thread
            work. Warm view switches are cheaper than a fresh open; no worker-based parsing or
            whole-document virtualization is claimed.
          
    • 
          
  • 
            The first typing pagination pass remains noticeable after input settles. The measured
            maximum is not lower than the previous optimized capture. Measurement caching reduces
            repeated work; the planner and browser layout can still occupy the main thread.
          
    • 
          
  • 
            The eight-input limit is deliberately soft. Protected active fields may exceed it.
            Suspended undo data remains in memory while its formula exists, and an incompatible
            library prevents suspension rather than risking data loss.
          
    • 
          
  • 
            The initial development dependency-cold attempt triggered Vite reload during capture and
            was retained separately. The accepted final development sequence uses a prepared
            dependency graph; no final compile-cold speedup is claimed. Native disk-cache setup also
            emitted a long-path warning; native measurements use explicit browser-cache clearing.
          
    • 
          
  • 
            Standalone browser and native results use different browser engines and shell overhead.
            A sampled event-loop lag does not identify its cause by itself; no unexplained whole-app
            freeze was reproduced in these bounded final sequences.
