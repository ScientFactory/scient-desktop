## Deliberately deferred upstream architecture

The upstream range replaces npm-managed server runtimes with self-contained executable archives and
connects that choice across CLI install/update/uninstall, background service restart, SSH, WSL,
five-target signing, npm launchers, and release publication. The official commits remain literal
ancestry, but this candidate does not activate that coupled architecture.

Scient's server distribution is currently a signed, npm-pinned runtime with additional PDF,
analytics, and scientific-compute workers. Its WSL/SSH lifecycle, managed-provider catalog, updater,
signing, and publication rules are also Scient-owned release boundaries. Partially adopting the
archive stack left worker lookup, Bun SQLite diagnostics, native module loading, preview-release
metadata, and service ownership inconsistent. Those residues were removed. The existing single
Scient runtime path remains authoritative until a separate design qualifies every worker and every
supported platform end to end.
