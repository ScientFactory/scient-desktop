## Composition

### Keep-awake: realigned onto T3

T3 now keeps the computer awake while agents work (#34128). The server holds the operating
system's own sleep block (`caffeinate`, `systemd-inhibit` or a PowerShell call), and a server
setting that is on by default controls it. Scient had its own version since October. The desktop
app held Electron's sleep block, polled the server every 15 s, was off by default, and offered a
per-thread "Keep computer awake until done".

T3's hold is now the one app-wide mechanism. It works for servers reached over SSH or run as a
service, and with no window open.

- **One marked change in T3's `KeepAwake.ts`:** "busy" is decided by Scient's definition of work
  (`scient/keepAwake/work.ts`). That counts executing work with a live owner. Monitors, pull
  request watches, threads waiting on a person or on another thread, and runs whose session is
  gone do not count. The check runs on every thread event and once a minute, so a session that
  ends without an event still releases the hold.
- **Settings:** Scient's desktop switch (`keepComputerAwake`) and its Settings row are removed, and
  T3's "Keep awake while agents work" replaces them. Stored settings with the old key still decode.
  The key is dropped on the next save.
- **Per-thread choice:** "Keep computer awake until done" on a thread stays for people who turn
  the setting off. The desktop holds it for the chosen threads only, and the menu item is hidden
  while the setting is on.
- **Branding:** the inhibitor names Scient.

People who had Scient's switch off, the old default, are now kept awake while agents work unless
they turn T3's setting off.
