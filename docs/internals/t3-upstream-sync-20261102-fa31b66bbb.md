## Composition

- **Managed policy.** The range's largest addition lets an administrator set defaults, lock
  settings and limit the permission mode, clients, providers and telemetry. Scient reads its own
  places: `/Library/Application Support/Scient/policy.json`, `C:\Program Files\Scient\policy.json`,
  `/etc/scient/policy.json`, the `com.scientfactory.scient` profile and
  `HKLM\SOFTWARE\Policies\ScientFactory\Scient`, so a T3 policy on the same machine does not govern
  Scient. Product text and `docs/user/managed-policy.md` describe Scient.
- **Telemetry limit.** Upstream gates its own ingest. Scient's analytics stayed outside that gate,
  so `AnalyticsService` now returns disabled when the policy denies telemetry.
- **Permission limit.** The new-thread strip's Permissions menu is Scient's and built its own
  options, so a limit never reached it: it offered Full access and the send was then refused. It now
  disables those modes with the reason. Found live. The orchestrator names the limit for both a
  dispatch and a provider-switch refusal, so a turn says who set it.
- **Provider limit.** Codex subscription sharing is checked after the policy vets providers, and
  the text-generation fallback skips providers the policy denies.
- **Delegated children.** Scient's settlement uses upstream's rule for background work that holds
  completion, and Codex thread parameters take the thread id (#28604).
- **Attached threads.** Upstream's MCP speedup skips a caller's messages (#28282). Attached threads
  read them, so `loadCaller` takes a flag and they still load.
- **OpenCode steers (#23270).** Steers carry Scient's runtime guidance beside the agent and variant.
- **Keybindings.** Scient's focus context stays, with upstream's editable check when it is unset.
- **Bare URLs (#27794).** `remarkKeepAutolinkSuffixes` joins Scient's Markdown profiles.
- **Dev seeding (#24665).** Upstream dropped the slot check. Scient's ledger stays strict, so its
  test for another migration below V2 goes and the other expects the ledger error.
- **`check:changed` (#28296).** Upstream's test split runs beside Scient's `node:test` detection.
- **Link cards (#28491).** Upstream's rule for old cards joins `waitsOnUser`.

  `packages/provider-fx` join the build guards of the runtimes that now import them.
