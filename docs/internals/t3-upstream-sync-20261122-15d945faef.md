## Composition

### Chat Markdown on Words (#27866)

T3 replaced react-markdown, remark and rehype in chat with Words (`markdown/wordsHast.ts`,
`chat/markdownRenderer.ts`, `chat/markdownIslands.ts`). Chat now renders only through Words;
Scient's behaviour sits in Scient modules mounted at marked seams in `wordsHast.ts` and
`ChatMarkdown.tsx`.

- **Math.** Scient's own grammar still decides what is math (single-dollar heuristics, `\(`/`\[`
  intent, pipes in tables, unclosed and oversized guards). Each formula reaches Words as a
  placeholder of the same length, so offsets stay as authored; a formula alone on its line(s)
  goes as a one-line heading placeholder so the blocks around it keep their structure. After T3's
  sanitizer the placeholders become the `language-math` code chat typesets with KaTeX
  (`scient/math/scientWordsMath.ts`). The authored source rides on the element, so Find and copy
  need no separate context. Words' own SVG math stays off. T3 deleted the KaTeX `%` repair Scient
  still uses; it now lives in `scient/math/katexPercentRepair.ts` with T3's test.
- **Direction.** `rehypeScientBidi` replaces T3's per-block direction pass inside `wordsHast.ts`;
  T3's `markdownTextDirection.ts` stays deleted. Its letter classes stay exported in
  `textDirection.ts` as T3 ships them (knip exception).
- **Images, rich fences, colour codes, citations, file links, streaming reveal.** Ported onto the
  hast and component seams. Scient's quote protocols moved into T3's new sanitizer owner
  `packages/shared/src/markdownHast.ts`; the LaTeX seam manifest points there.
- **Copy message.** Renders the Words chat tree with the clipboard components, so the copied
  flavour matches what chat shows.
- **Saved files and notebooks.** T3's inert Markdown (file previews) also shows Plotly and
  Vega-Lite fences as source. Live notebook cells get their own Scient mode: links, images and raw
  HTML are inert as before, while inline code and diagrams render.
- **Document page.** Stays on its own remark pipeline as a Scient print surface. Remark therefore
  stays in Scient's web bundle, and a message that may hold math pays one remark parse for the math
  grammar. `remark-rehype`, `mdast-util-from-markdown`, `micromark-util-combine-extensions`,
  `micromark-util-types` and `vfile` left `apps/web`.
- **Raw `<script>`** in assistant HTML now shows as escaped text (GFM's tag filter) instead of being
  removed; it never becomes an element.

### Sending, queue and composer

- **Image wait (#40672).** A send made while an image compresses now waits and sends once it is
  ready, instead of the composer holding it. Scient's send context no longer counts compressing
  images as pending work (which would have dropped the send). A send released from the wait passes
  Scient's "left this thread" check, a direct prompt never waits, files staged with the images do
  not cancel it, and a post to the people in a thread waits the same way.
- **Dropped socket, missed steer (#40703, #40622).** Taken. Scient's rule that a Stop holds the
  queue until Send or Resume stands: T3's new test expecting a Stop-held queue to resume after a
  missed steer expects it to stay held in Scient.
- **Slash commands and handoff (#30261, #40764, #40670).** T3's slash-command deferral, prompted
  Resume and dropped-prompt restoration compose with Scient's history resolver, provenance and
  native-acceptance rules in `ProviderTurnStartService.ts`, `ContextHandoffDelivery.ts` and
  `RunExecutionService.ts`. T3's token-cap configuration read stays out; Scient's policy supplies
  the cap.
- **Paste (#40909, #40686).** Taken; Scient files non-vision images as attachments, so any `image/*`
  counts as a pasted picture. A TIFF beside other text now pastes as text (Word and Pages add one).
- **Queue previews (#40924).** `@`-file links show by name in Scient's own queue preview too.
