## Composition

### Translation (#37893)

- **Structure:** T3's translation calls (`<T>`, `gt()`, `msg()` with `m()`/`useMessages()`, and
  the `MessageResolver`/`MFunctionType` parameters) are adopted in every conflicted file. Scient's
  wording inside T3 files stays Scient's, inside T3's call. Scient copy added in T3 files is
  translated the same way.
- **Catalogs:** regenerated with `gt generate`. The 768 keys that are not in T3's catalogs (609
  web, 129 mobile, 30 desktop) are translated in all nine locales. T3's terms and formality were
  followed. The i18n check passes.
- **Scient's own modules stay English:** `t3code/no-untranslated-copy` is turned off for
  `SCIENT_ENGLISH_ONLY_FILES` in `vite.config.ts`. That list covers `**/scient/**`,
  `**/*.scient.*` and 48 Scient-only files. These modules hold about 7,300 strings, and
  translating them is a separate owner decision. The rule lists Scient, Scient Connect and
  Scient Agent as proper nouns.
- **T3 API changes in Scient code:**
  - Clipboard copies take a `ClipboardTarget`.
  - Settings rows use `useSearchableSetting` and the new reset-button props.
  - `useEnvironmentSubscription` takes a resolver.
  - Office pages take a `kind`.
  - The browser-import failure labels gain Scient's six reasons.
- **Tests:** Scient unit tests that render translated components mock `gt-react` with English
  (`scient/testing/englishGTReact.ts`), as T3's unit tests do. A server test that loads the mobile
  presenter mocks `gt-react-native` the same way.
- **Product copy:** prompt links, OpenRouter speech disclosure, Muse failures, MCP tool display
  names and logo, work-log sentences, contract labels and the composer banner context name
  Scient. The T3 Chat brand-allowlist entries move to their new lines.
