## Composition

### Linked environments refresh existing sessions (#26737)

T3 now gives a running agent the linking tools when Linked environments changes. A shared runtime
(Codex) reloads only the idle thread; an exclusive runtime (Claude, ACP agents) is reopened on its
next turn unless unfinished work would be lost.

Scient's provider session manager closes sessions through its own exact-owner path, so T3's
removal step was composed into it:

- As in T3, the "keep if unfinished" check and the removal share one request permit, so a request
  persisted meanwhile is never cancelled. Scient reserves its closing owner inside that same hold;
  no adapter takes the request permit while holding its own reservation fence.
- Scient reserves a session for each turn before opening it, and that reservation declines idle
  releases. T3's reopen runs inside that same turn's open, so it was always declined: found live,
  Claude kept the linking tools after they were turned off. The reopen now comes from the
  reserving start itself (`releasedByReservingStart`), which then opens the replacement. A Scient
  test covers a reopen while the start holds its reservation.

### HTML tools take a file path (#32833)

Agents can pass an absolute `.html` path to `html_preview` and `html_render`; the server reads it
only for full-access threads. Scient's chart-fence wording keeps the new option.

### Codex (#31149)

Tool calls no longer wait for reasoning summaries. Scient's two forked-thread Codex recordings
start threads with the new setting, as T3's recordings do.

### Other changes

- **Handoff budget (#23821):** oversized messages are skipped before they are measured; Scient's
  shared measuring helper stays.
- **Antigravity `agy` CLI (#32503):** a custom path may name the `agy` CLI, which has no harness.
  Scient's leased-release test checks the harness path that can now be null.
- **Preview screenshots (#28255):** saving a snapshot asks the page for the uncapped screenshot.
