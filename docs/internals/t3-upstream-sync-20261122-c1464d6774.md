through `15d945faef4c14099ba3d82bcdb84e91b5a3c3cd`. No donor commit was replayed, squashed or

## Composition

### Feature flags (#40594)

- **GitHub sign-in.** T3 now reads the GitHub app's client ID from the `github_app_client_id`
  entry of `T3CODE_FEATURE_FLAGS`, not from `T3CODE_GITHUB_APP_CLIENT_ID`. Scient's environment
  default would have stopped working silently, turning GitHub sign-in off. Scient's default now
  wraps T3's flag service for the source control drivers
  (`scient/sourceControl/ScientGitHubApp.ts`): Scient for GitHub when no ID is named and the
  operator's ID when one is. T3's flag list reads an empty value as unset, so the earlier way to
  turn the app off with an empty variable is gone; a different app can still be named.
- **Secrets.** T3's server flag `secret_providers` replaces the web build flag. It is off unless an
  operator turns it on, so the Secrets page stays hidden as before. The sidebar composes T3's
  flag-aware groups with Scient's desktop-only Voice entry. Stale mocks of the old flag were removed.
- **CLI and tests.** Scient's `project` command builds the source control drivers itself, so its
  runtime provides T3's flag layer; the server test kit and the CLI test harnesses provide T3's
  test layer, as T3's own tests do.
- **Docs.** TanStack Source's setup says to restart Scient; the internal GitHub app note names the
  new flag.

### Queue and steering

- **Slash commands wait (#40316).** T3's dispatch rule is taken next to Scient's
  `executionThread`. Queued-message "Send now" tooltips and the composer guide take T3's text
  inside Scient's held-queue paragraph.
- **Delegated tasks (#37225).** Scient's delegated-child settlement subscription now calls T3's
  retrying parent update instead of its own one-shot finalizer.

### Dictation sent after a thread switch (#40553)

Scient's send is a stable callback that always runs the latest render, so handing it out as T3
does would send a dictation to whichever thread is on screen. The hook keeps the render's own send
(`sendFromRender`) and `captureDetachedSend` returns that one. A detached send passes Scient's
"left this thread" check when its stored draft is unchanged, resets the composer only when its
thread is on screen, frames the sent message only there, and keeps a held send's steer request.
A dictation that answers a shown approval is not sent detached; its text stays in that thread's
draft.

### Files and previews

- **PDF links (#40507).** Not needed: Scient's PDF reader runs on PDF.js's link service, where
  links already open. T3's `PdfViewer` and its test stay removed.
- **Files tree (#40308).** The hover title for clipped names applies to Scient's tree.
- **Image thumbnails (#40501).** T3's colour space joins Scient's square and snapshot thumbnail
  modes.
- **RTF text (#40476, #40437, #40468).** T3's font charset state is taken with Scient's
  `node:util` decoder.
- **Right panel (#40215).** The workspace revision reaches T3's panel surfaces; Scient's surfaces
  keep their own refresh.

- **Windows PATH listings (#40634).** T3's process-wide listing cache is taken; Scient's cached-miss

- **AppImage launcher (#40624).** T3's new signal cases run inside Scient's Unix-only block.
- **npm launcher test (#40475).** Scient ships no npm launcher; the test stays removed.
