## Composition

### Stricter Effect rules (#31111, #31216, #31217, #31218)

T3 turned about 45 more Effect diagnostics into errors and moved its own code to them: errors are
`Schema.TaggedError` classes, every `Effect.try` maps failures to a typed error, and Effect code
reads the environment through `HostProcess.Environment`. T3 fixed its code instead of switching the
rules off, and Scient does the same for its own code (`23a3578c6d`, about 300 diagnostics in about
175 files):

- `process.env` inside Effect code reads `HostProcess.Environment`, which defaults to the live
  `process.env`, so nothing changes at runtime. Scient tests that changed `process.env` now inject
  the environment the way T3's tests do.
- `Effect.try` and `Effect.tryPromise` map failures to the module's existing error where one
  exists, otherwise to a small private tagged error.
- Native and `Data.TaggedError` classes become `Schema.TaggedError` with the same tags, fields and
  messages. Some constructors now take an object instead of positional arguments; every call site
  is updated. `instanceof` on these classes becomes `Schema.is`, as the rules require.
- Classes in packages without an Effect dependency, and `RetainedMutationError` (built
  positionally at about 120 sites in plain async code), stay native under T3's one-line
  `extendsNativeError:off` comment.
- One message improves: Overleaf scratch-setup failures now carry the real cause in `detail`
  instead of Effect's generic "An error occurred in Effect.tryPromise". The reason and tag are
  unchanged.

## Removed: Scient's desktop page release

Scient added `releaseDesktopConnections` in `021617d354` (Oct 30): before an agent was refused a
tab at the server limit, it freed other conversations' idle desktop pages. Since `e6599bc0f5`
(Oct 31) it has freed nothing, because it skips tabs whose `recording` is `undefined` while tabs
start with `null`. T3's #24186 now frees idle agent tabs at the same point, so the alignment
removes Scient's function, its two-minute idle constant and its running-agent tracking, and keeps
T3's code as is. Nothing changes at runtime.

T3's version does not free pages the user opened. That case is a follow-up, added as one marked
step on top of T3's reclaim.
