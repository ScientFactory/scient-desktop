## Composition

### Agents and providers

- **Pi starts attached to its session (#21512):** taken. T3's adapter shape is adopted: Pi
  launches with `--session <file>` right after `--mode rpc`, checks the session header's cwd before
  spawning on it, respawns on a fresh owned file when Pi rejects the spawn session, and skips
  `switch_session` when the launch is already attached. Scient keeps its owned empty session
  files (in their own scope, released after the process), its ordered transport scope, startup
  rollback, injected connection, tool-name map and ownership checks. Two composition fixes:
  - Scient's first registration binds the launched owned file; only a provider thread whose
    native ref was cleared asks Pi for a new session, as T3's resume tests need.
  - Session identity compares paths after resolving them against the cwd, since Pi can report
    the attached file with a different spelling.

  Scient's replay harness now expects the owned `--session` pair after `--mode rpc`. Recorded
  `switch_session` frames to a file Pi already reports (after a rollback `fork`) stay in the
  recordings as historical frames and are not executed.

- **Failed turn starts (#14424):** taken. Scient's queued `provider-turn.start` still carries its
  expected attempt, and a stale attempt returns before T3 captures the starting run, so it never
  settles a newer run.
- **Delegated tasks without the parent's history (#34551):** taken. Scient's attempt-aware Stop
  check now runs only after T3's interrupt-request index finds a Stop row, so starting and
  finishing a delegated task no longer reads the parent's runs.
- **Claude goals (#30646):** taken; every Claude query carries T3's Stop hook.
- **OpenCode background replies after a turn settles (#36887):** taken. Scient's per-turn
  permission write and readback now also run before a continuation admits the wake OpenCode
  already runs. Scient's OpenCode replay adds the synthetic confirmation where a recorded wake
  starts. A continuation that adopts a live wake marks its provider turn natively accepted, so an
  interrupted run's retry does not hand the wake's history over again (an upstream gap too).
- **Cursor native resume (#36918), ACP cancel ordering (#30846), plan replacement (#36978),
  queued native child continuations (#21461):** taken; Scient's Cursor grants and turn-start error
  mapping and its ACP send hook stay. Cursor advertises compaction only when enabled, as T3 does.
- **Forwarded thread waits (#15622):** taken. A forwarded `scient_thread_wait` is one call capped
  at 45 s, like a local one; Scient's 50 s chunk loop is removed. Remote delegation already repeats
  timed-out waits.
