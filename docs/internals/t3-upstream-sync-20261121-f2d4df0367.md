## Composition

### Agents and MCP

- **Background waits (#38348).** T3's `background-wait` grant replaces Scient's own caller flag
  for the same purpose. Scient's session-aware detection (a runtime that can await background
  tasks) now issues that grant, so the wait tool's visibility, the thread-only guard and credential
  reuse follow T3's capability; `shownWithBackgroundWait` and the registry's `backgroundWait` field
  are gone. Cursor's new wait guidance goes through Scient's agent copy, so it names
  `scient_background_wait`.
- **Typed turn results (#38874).** The new tool is `scient_submit_output` (tool, handler, Claude's
  read-only allow list, the run's result instructions and the MCP doc), as every Scient thread tool.
- **MCP sign-in (#39921).** The two RPCs join the server-management group beside the other provider
  RPCs. Claude's live query and the replay testkit gain the three control requests.
- **Secret cards (#31257).** Multi-value cards are taken. Accounts cards keep Scient's privacy note;
  the phone keeps its one-tap code entry for single-value sign-in codes.
- **Cursor (#39526, #38348, #39605).** The out-of-process SDK runner and its text generation are
  taken. Scient's host runtime instructions compose with T3's resend-only-on-change rule.
- **ACP (#39949).** The Windows terminal-tool launcher is written once per adapter and passed into
  Scient's per-session MCP context, which keeps its connector bridges.
- **Antigravity skills.json (#39765).** Config-listed skill folders compose with Scient's plugin
  skills; a machine-wide scan without a project reads only the user's `skills.json`.
- **Orchestration copy.** T3's provider-instruction part of the first prompt composes with Scient's
  host copy and wrapper.

### Web and desktop

- **Side threads (#39515).** Saved `side-chat` tabs become `thread` tabs. Scient's right-panel
  storage version moves 19 → 20 so existing tabs migrate; Scient's Agents and Scient surfaces stay.
  A quote joins a side chat tab, never a known subagent tab. "Open in main view" joins Scient's tab
  menu beside Open in new window and Duplicate.
- **Read-only timeline (#39406).** The guest page and linked threads share T3's read-only timeline,
  which uses Scient's reading follow and Scroll to end control.
- **Usage limits (#39889).** T3's "Reset {time}" copy composes with Scient's Continue with.
- **File previews (#39736, #34769).** T3's dependency-aware revisions apply to HTML pages; exact
  files keep Scient's revision, now from T3's `mediaFileRevision`. Scient's watcher-driven HTML
  preview stays, so T3's frame and grant-renewal rewrite is not taken (see Deferred). The copy
  button is taken.
- **WSL home (#39771).** Not taken in substance: Scient keeps WSL state in `~/.scient-next`, so a

  and Scient still uses; it is restored.
- **Update track notice (#38506).** Not taken in substance: Scient still offers a newer build of
  the saved track to a build from another one, so no offer means up to date. T3's state field and
  renderers stay unused; its mismatch tests are removed.
- **Apple Speech (#34027, #40011).** Taken literally and dormant, with the rest of T3 voice: the
  macOS package builds the helper (macOS 26 runners have Xcode 26), and the plist's speech
  recognition reason names Scient. Scient voice is unchanged.
- **Service log (#39857).** T3's piped log output composes with Scient's Node-package launch.
- **Windows resource monitor (#39683).** Scient's release, Windows and Linux packaging caches key
  on `.cargo/config.toml`, so the static-CRT build replaces a cached one.
