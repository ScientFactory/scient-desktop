## Friction measurement and resolutions

The merge produced 14 textual conflict paths, all at known inherited or
Scient-owned policy seams. No Scient-owned package under `apps/web/src/scient`
was changed.

1. Release workflow and operations documentation retained Scient signing,
   updater, versioning, and publication authority. T3's AUR workflow and AUR
   user promise were not enabled.
2. Desktop configuration, startup, and packaging adopted the WSL managed-server
   tree and Windows `server.asar` sidecar while preserving Scient state roots,
   safety variables, resource monitoring, local voice, and the
   `@napi-rs/canvas` PDF runtime.
3. The server manifest retained Scient's XML dependency and adopted T3's new
   native msgpack dependency. The lockfile was regenerated from the combined
   manifests rather than hand-resolved.
4. `ChatMarkdown`, `ChatView`, sidebar, settings, and global styling retained
   Scient math, diagrams, RTL, right-panel, identity, typography, and provider
   mounts while adopting T3's surrounding layout and interaction changes.
5. T3's new agent-awareness runtime is supplied with Scient's existing secret
   store at one composition boundary. No provider credentials or ownership
   model moved into inherited UI code.
6. Mobile active-turn behavior uses the selected environment instead of
   assuming a project, preserving General Chat and other projectless threads.
7. The new WSL state-root regression uses `SCIENT_NEXT_HOME`; no obsolete
   `T3CODE_HOME` authority was reintroduced.
8. A stale Scient wordmark regression was updated to assert the current
   stylesheet-backed desktop-width contract rather than old utility classes.
