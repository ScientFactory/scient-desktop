# T3 upstream alignment, 2026-11-20 (0317d4f4e5)

## Scope and history

This alignment integrates, in one literal merge, the 161 official commits after `0317d4f4e5`
through `f6d941fa4fa41741a881b8f646c6737d845ea91c`. No donor commit was replayed, squashed or
dropped.

The range is mostly fixes: Antigravity sign-in, steering and limits, delegation and subagents,
faster turn starts on long threads, remote environments and SSH, and chat details. New features
are side chats added to their main thread, forwarding another environment's ports, and a setting
that turns off the preview tunnel. One T3 policy, Antigravity's 1.5 floor, would have refused
Scient's default runtime and is not taken (see below).

This record describes the committed integration, not delivery or release acceptance.

## Composition

### Antigravity

- **The 1.5 floor (#38970) is not taken.** T3 removed ACP-harness support and rates every
  Antigravity below 1.5 broken. Scient's default managed runtime is the qualified 1.4.5 harness,
  so that rating would refuse every Scient session and the default install. The manifest keeps
  Scient's Antigravity entries and gains only T3's `versionPattern`. The driver keeps the harness
  paths T3 deleted: the harness's own `yolo`/`auto_edit` modes (only the agy CLI maps them), ACP
  `authenticate` sign-in instead of `--login`, the 1.4.5 prompt quirks (`run_workflow` filter,
  system-prompt append, native file reads, MP4 linking) and the harness recovery tests.
  `antigravityRelease.ts`, which T3 deleted with the harness, stays for Scient's catalog.
- **Auto review (#39378)** applies only to sessions whose start result offers native Auto. The
  harness offers none and keeps answering from the runtime policy, as before.
- **Usage limits (#38957)** never read the agy CLI's shared OS keyring item; limits come from the
  instance's own profile, as before. On macOS the background read waits on a Keychain access
  prompt and holds one of Node's four file-I/O workers. In the live test, with `agy` on `PATH`,
  every worker waited on the prompt and Files and Library never loaded.
- **Broken-version refusal (#39427).** The driver's new initialize-time check uses Scient's
  release-scoped manifest lookup; T3's direct `providerCompatibility` lookup is routed through it
  too, so fetched upstream ranges never reach shipped builds.
- **Sign-in (#28355, #38953, #39443), steering (#39165), host sleep (#39395), temporary-file
  cleanup (#39275), UTF-16 attachments (#39456)** are taken beside Scient's diagnostics, bounded
  markers, sidecar sweep and process-group teardown.

### Orchestration and MCP

- **Faster turn starts (#39103, #39241, #39325, #39391).** T3's narrower reads replace history
  scans; Scient still reads full history for image prompts and counts fork history in shell item
  counts.
- **Agent messages (#39306, #39417).** Steers and queued agent sends carry T3's sender note, which
  now names Scient. An agent's automatic send queues behind earlier agent messages and respects
  Scient's per-run queue hold. T3's "a restart Stop already reached starts immediately" is not
  taken; Scient refuses that case (Stop first).
- **Delegation (#39247, #39413, #38869).** Project-config model rechecks sit inside Scient's
  usable-instance hints; Antigravity thinking-level IDs are checked before Scient's fuzzy model
  match. Scient's invocation-policy check still guards `delegate` and `createThreads`.
- **Worktree launch (#38459)** replaces Scient's own HEAD-check fix; Scient keeps the C locale. A
  branch whose tip commit is missing now gets a worktree, and a worktree whose Git folder is gone
  starts in the shared checkout, as T3 does.
- **Codex (#39414, #37442, #39086, #39458).** Codex stdio MCP servers receive `T3CODE_THREAD_ID`
  beside Scient's owned servers; the per-thread config read and thread-name request are added to
  Scient's recorded replay fixtures at load time (`testkit/CodexReplayThreadSetup.ts`), so the
  imported fixtures stay byte-identical.
- **`/logout` (#39027)** needs `providers:manage` on Scient's dispatch handler too.

### Providers, SSH and shared

- **Minimum versions from the manifest (#39434).** OpenCode and Pi read their floor from the
  manifest. Pi below 0.84.3 is broken and 0.84.3 unsupported from Scient 0.6.32; older releases
  keep their rating.
- **Pi.** Pi sessions get the pull request linking rules (#31727). T3's `mcp__t3_code__` aliases
  (#26845) are not taken: Scient's Pi bridge registers bare tool names and already moves saved
  prefixed loadouts onto them.
- **Atomic saves (#24310)** keep file modes and fsync; Scient keeps its explicit `mode` override
  and adds `EOPNOTSUPP` to the unsupported-sync list.
- **SSH (#39184, #35307, #30616)** use Scient's `~/.scient-next` remote home.
- **Stalled download retry (#38038)** is not used: Scient installs the pinned runtime with npm.
- **Client commands as Effects (#38912).** Scient's account, Sources and inventory commands move to
  `runAtomCommand`; an awaited `.run` would otherwise have stopped running them, silently.

### Web and desktop

### Found in review and live test

Codex reviewed the composed tree; the live dev-app test ran on the pushed head. Each finding was
checked against the code:

- **Broken worktree launch.** T3's HEAD probe (#38459) treated "not a git repository" as a plain
  folder, so a project whose `.git` points at a missing directory ran its first prompt in the
  shared folder. The fallback now applies only when the folder has no `.git` at all; otherwise the
  launch is refused, as Scient did before.
- **agy CLI sign-in code.** Scient's setup bridge always submitted a callback URL; the CLI's code
  login now submits the pasted code through the controller's `respond`, and the setup asks for a
  code. The 1.4.5 harness keeps the callback URL.
- **Keyring stall.** See Usage limits above; found when Files and Library never loaded in the live
  app.
- **Not changed:** an OpenCode prerelease such as `1.14.19-beta.1` now rates as its release
  version, because T3's `versionPattern` strips the suffix; Scient takes T3's rule.
- **Redundant:** Scient's token-limit banner dismissal test duplicated T3's per-source key test and
  is removed.

### Not taken

- Antigravity's 1.5 floor and harness removal, Pi's prefixed tool aliases, the off-track update
  message, the restart-Stop fast path, and T3's dev-runner live-home rule: Scient's safety envelope
  already keeps dev servers out of `userdata`.
