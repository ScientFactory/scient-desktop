## Composition

### Antigravity

- **Sign-in per instance (#39485).** Google-account instances launch with T3's `SSH_CONNECTION`
  marker, so the 1.5 CLI keeps each sign-in in the instance profile instead of one shared keyring
  entry, and usage limits read that file. The keyring is now offered only for Gemini Enterprise,
  and Scient's opt-in stays off: Scient never reads the shared item (a macOS Keychain prompt holds
  one of Node's four file-I/O workers). Enterprise instances on the 1.5 CLI show no limits.
- **Global rules (#39531).** `AGENTS.md` and `GEMINI.md` link into the profile beside the skill
  folders. Scient's dangling-link guard applies to the folders only; a rule file links while it
  exists. Scient's plugin-skill projection runs after the links, as before.
- **Managed CLI self-update (#39363).** T3's read-only release folders, managed-directory lock,
  symlink checks and "changed on disk" detection cover Scient's 1.4.5 pair: the harness is locked
  and size-checked with the executable. Scient keeps its repair, which holds the previous copy in
  `.repair-*` outside staging until the replacement is active, and now restores it when activating
  the replacement fails, as T3 does. Renames and removals go through Scient's Windows-retrying
  installer filesystem. A Windows launcher still pairs its harness: T3's lock-free external lookup
  leaves launchers to the full lookup. A failed startup check shows the check's own detail.
- **Killed subagents (#39519) and MCP tool names (#39474)** are taken unchanged.

### Orchestration, MCP and server

- **Callers that go away (#36499).** A delegated child's preparing run is committed and prepared
  uninterruptibly; Scient's `task_projection_missing` failure class stays on the missing-task path.
- **Thread viewers (#39502).** The event sink and thread subscriptions share T3's viewer registry;
  Scient's server harness and its own event-sink tests provide it.
- **Exact workspace links (#39491)** recheck the target's preview type and keep Scient's file
  revision.
- **Linux keep-awake (#39490)** inhibits sleep only and keeps the `Scient` inhibitor name.
- **Relay (#39482, #39498)** changes no migration or variable; the key-mismatch advice names
  Scient Connect.

### Web
