## Composition

### Cursor usage (#32448)

T3 now reads Cursor usage only for the account signed in to the app or set as `CURSOR_API_KEY`,
and no longer reads the Cursor CLI's login from the macOS Keychain. The Keychain reader, its
setting and its Settings row are gone. Scient's changes there only named Scient in the Keychain
message and kept the read off by default, so they go with it, along with Scient's tests for that
default. Scient's Cursor driver factory and its usage-accounting settings stay.

### Voice (dormant)

T3 adds opt-in cloud dictation (OpenAI, Grok, OpenRouter), a sortable model list and an easier
first-run setup. The environment reports neither local nor cloud transcription
(`SCIENT_T3_VOICE_TRANSCRIPTION` in `ServerEnvironment.ts`). T3 now also offers its microphone as a
first-run setup when no destination is chosen, without asking the server; Scient turns that offer
off (`apps/web/src/scient/voice/t3VoiceDormancy.ts`), and T3's tests turn it back on to cover T3's
behavior. So every client keeps hiding T3's voice controls; Scient's voice stays the one users see. The composer passes T3's new setup props
through to its hidden setup dialog. The citation comment editor keeps Scient's version.

### Browser

T3 strips the `Electron/` token from requests to Microsoft Teams with its own header listener.
Electron allows one such listener per session, so T3's would replace Scient's site identity rule,
which already sends every site, Teams included, a User-Agent without that token. Scient's rule
stays the only listener; T3's Teams test checks Scient's rule instead.

### ACP

- **Form questions (#19659):** T3's new form parser replaces the inline one Scient had extended
  with titled choices; T3's parser reads titled choices too, shows their titles and answers with
  their values. Scient's Droid tests expect that shape.
- **Raw notifications (#19585):** the unread backlog is bounded by count and JSON length. Scient's
  decoded-batch fence keeps its order and logs decoded messages only when incoming logging is on,
  as T3 now does.
- **Child tool output (#32411)** merges as upstream.

### Pi

- **MCP extension file (#32231):** written atomically, with Scient's host-specific instructions.
- **Thinking across model switches (#32389):** Scient's selection path already sets model and
  thinking together and confirms them. T3's change that marks the session's own thinking as
  applied is left out: in Scient nothing counts as applied until a selection is confirmed, and an
  untouched native default stays Pi's. T3's new tests pass against Scient's path.

### Other server changes

- **Service install (#23878):** a service serving another home is reported and left alone, in
  Scient's wording and `scient` command.
- **Provider installs:** T3 turns provider installation into a service; Scient's test server
  provides it over its mocked installations.
- **Port scanning (#30011):** Linux reads `/proc` before `lsof`. Scient lists only declared URLs,
  so T3's new tests name theirs and read terminal ownership. Scient's real-Python scanner test (Linux CI) now confirms
  the kernel's listener with its own `lsof` query when the scanner read `/proc` instead.
- Antigravity's SOCKS hint, the usage-limit resume after restart, PR discovery after restart and
  English git errors merge as upstream.
