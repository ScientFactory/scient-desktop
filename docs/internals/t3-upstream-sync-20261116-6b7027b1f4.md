- **Work a dead provider process was running (#37325, ACP #37377):** taken. When a provider's
  event stream fails on its own (not one T3 or Scient ended), open root commands and dynamic tools
  are interrupted from their stored rows, and subagents that outlived the root run fail. The
  cleanup sits beside Scient's run-owner finalization: a rejected finalization owner still returns
  without ending work, and the lost tool calls are written after Scient's cascaded subagent events.
  T3's per-subagent projection also carries Scient's runless workflow-member link, so a linked
  member's node ends with it.
