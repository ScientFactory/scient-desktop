## Composition

- **Held queues (#27221).** Upstream releases held agent, server and scheduled messages
  when a later run completes. Scient releases a hold only on an explicit Send or Resume
  (`QueuedRunSend.ts`, `TerminalQueueHold.ts`), and its fence re-holds any other release,
  so upstream's release is omitted rather than composed into churn: those messages keep
  waiting for Resume, as before. Upstream's test for the release is removed and its
  provider-wake test keeps Scient's expectation. Whether such messages should resume on
  their own is an open product question.
- **Stop (#27252, #27141, #27222).** Stop always completes and an agent that ignores it
  can be force-stopped. Scient keeps provider-work admission, held-queue Stop, its
  outcome shapes and the held-Droid-input interrupt; upstream's unresponsive outcome
  dispatches `thread.interrupt.unresponsive`. The 15 s Stop timeout wraps only the
  provider interrupt in Scient's session retirement, which keeps its own 30 s close
  wait. A Claude Stop that both times out and fails to close shows Scient's "Stop failed"
  item and upstream's Force stop. Restart continuations retry failed starts and respect a
  parent's Stop; the continuation test enables Scient's off-by-default continuation
  setting for its project only.
- **Provider registry.** Scient's own reconcile lock and stored config map give way to
  upstream's equivalents; Scient's rebuild and unresolved-credentials check sit on them.
  Settings refresh also asks to reload secrets, which does nothing without a secret
  reference. Environment values that are unresolved secret references are skipped when
  agents start.
- **Server under pressure (#27176, #27239).** Agents yield CPU, IO and tasks to the
  server under Scient's `app-scient.slice`. `service protect` joins the `service`
  commands, which Scient builds do not register, so the background-service guide is
  unchanged.
- **Media-only messages (#26769).** Upstream's bubble-free layout applies; Scient's image
  gallery replaces upstream's single-image and collage layouts. The queue preview shows
  nothing for an image-only message.
- **Usage (#24139).** The scan cache moves to version 10 for Claude advisor calls.
- **check:changed (#27227).** Upstream's Effect rewrite with bounded concurrency carries
  Scient's literal Git paths and Node test runner; both test files merge.
- **Brand and CI.** The Claude mod message, protect messages and sidebar logo label name
  Scient. Upstream's new fork EAS preview workflow is off, like `mobile-eas-preview.yml`.
- Durations under 10 s drop a trailing `.0` (Scient's timeline tests follow). The
  composer rich-text toggle was added and reverted upstream within this range. No
  migrations were added. The lockfile adds the three new packages and keeps main's 127
  `hasBin` markers.
