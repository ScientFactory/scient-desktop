  membership recorded when the fork was created. Scient's readers take the same filter through
  one helper, `forkInheritedThroughRuns`, so the bounded portable-fork read (Scient's default)
  gets T3's fix too. Only a run fork records membership: a Scient fork, whose frozen rows are its
  own record, and a side chat read their runs unfiltered, as before. Callers pass the fork thread.

  The composer asks for approval after Scient's draft checks, under the send it already holds.
  The server test kit stands in for a person, so the lint rule that keeps the approval writer out
