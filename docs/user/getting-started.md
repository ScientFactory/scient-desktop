# Getting started with Scient

Scient is a workspace where an AI can help with the real files, tools, and
outputs of your project. Getting Started gives you a short path from opening
Scient to doing that first piece of work.

1. **Connect your AI.** Choose a provider and follow its install or sign-in
   step. The provider supplies the AI models; Scient gives them the project
   workspace and controls. See [Providers in Scient](providers.md).
2. **Open a project.** Add an existing folder or create a new one. A scientific
   project can be an analysis, experiment, manuscript, literature review, code
   repository, or any other folder whose files belong together. See
   [Work inside a project](projects.md).
3. **Message Scient.** Open a conversation, choose the model and permission
   mode you want, and describe the result you need. The AI can inspect the
   project and use its available tools rather than relying only on text pasted
   into chat. See [Message Scient](composer.md).

Voice dictation is optional. To set it up, open **Settings → Voice**, choose a
speech model, and follow the download or permission step shown there. See
[Voice dictation](voice-dictation.md).

On a new, empty workspace, the Getting Started flow can connect a provider,
save a few optional local preferences, and add your first project. You can skip
it at any time. To reopen it later, use **Settings → General → Getting
started**.

Provider installation and sign-in use the same provider-owned account flows
available elsewhere in Scient. Work preferences and an optional custom answer
are saved only on the current device.
