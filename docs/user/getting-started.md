# Getting started with Scient

On a new, empty Scient workspace, Getting Started can help you connect an AI, save a few optional
local preferences, and open a project or Quick Chat.

You can skip at any time. Scient will not show the automatic flow again after you skip or finish it.
To revisit it later, open **Settings → General → Getting started**.

Provider installation and sign-in use the same secure provider setup available elsewhere in Scient.
Work preferences and an optional custom answer are saved only on the current device for now.
