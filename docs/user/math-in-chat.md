# Math in chat

Mathematical notation in chat responses renders as typeset math instead of
raw notation.

- Inline math: `$...$` or `\(...\)`.
- Block math, shown on its own line: `$$...$$`, `\[...\]`, or a ` ```math `
  fence.

Rendered Markdown file previews get the same treatment for dollar-delimited
math.

Dollar amounts in ordinary sentences, like "it costs $5 and $10 today," stay
plain text — Scient only typesets notation that reads as math.

If a formula can't be rendered, Scient shows the original notation as typed
instead of leaving it blank.

Math renders locally on your device; no network request is involved.
